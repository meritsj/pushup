# 아이폰에 설치하기

## 1. GitHub Pages에 올리기 (무료, 5분)

1. github.com에서 새 저장소 만들기. 이름 아무거나, **Public**
2. `Add file` → `Upload files` 로 이 폴더의 파일 전부 올리고 커밋
3. `Settings` → `Pages` → Source `Deploy from a branch`, 브랜치 `main` / `(root)` 저장
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 가 열립니다

## 2. 홈 화면에 붙이기

1. **Safari로** 그 주소를 엽니다 (크롬 아님)
2. 하단 공유 버튼 → `홈 화면에 추가`
3. 홈 화면 아이콘으로 실행하면 주소창 없이 전체화면으로 뜹니다

# 기록은 어디에 저장되나

**GitHub에는 앱 코드만 올라갑니다. 운동 기록은 GitHub으로 가지 않습니다.**
저장소를 공개로 두어도 기록은 아무도 볼 수 없습니다. 서버로 나가는 데이터가 없습니다.

기록은 **이 아이폰 안 두 군데**에 동시에 저장됩니다.

| 저장소 | 언제 쓰나 |
|---|---|
| 브라우저 저장소 (localStorage) | 세트를 누를 때마다 |
| IndexedDB | 같은 시점에 한 번 더 |
| 날짜별 스냅샷 | 하루 운동이 끝날 때, 최근 10일치 |

앱을 끄거나 홈으로 나갈 때도 한 번 더 저장합니다.
앱을 다시 열면 두 저장소 중 더 최신인 쪽을 자동으로 불러옵니다.
그래서 껐다 켜도 기록은 그대로 있습니다.

설치할 때 브라우저에 "이 데이터를 지우지 말아달라"고 요청도 보냅니다.

## 그래도 사라지는 경우

- **Safari → 방문 기록 및 웹사이트 데이터 지우기** 를 실행한 경우
- 홈 화면에서 앱을 삭제한 경우
- 아이폰을 바꾸거나 초기화한 경우

이때는 두 저장소가 함께 사라집니다. 그래서 파일 백업이 따로 필요합니다.

## 파일 백업

하루 운동을 끝내면 완료 카드에 **파일로도 남기기** 버튼이 뜹니다.
누르면 공유 시트가 열리고 파일 앱이나 iCloud 드라이브에 저장할 수 있습니다.
'기준' 탭에서도 언제든 같은 버튼을 쓸 수 있습니다.

파일 저장은 자동이 아닙니다. 아이폰이 사용자 터치 없이 파일을 저장하는 것을 막기 때문에
한 번은 눌러야 합니다. 2주에 한 번, 최대 테스트 하는 날 같이 누르시면 충분합니다.

**복원** — 백업 JSON 파일을 열어 전체 복사한 뒤,
'기준' 탭 붙여넣기 칸에 넣고 `복원하기`를 누르면 됩니다.
