# 아이폰에 설치하기

파일 5개(`index.html`, `sw.js`, `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`)를
HTTPS 주소 하나에 올리면 끝입니다. HTTPS가 아니면 서비스워커가 안 돌아 오프라인이 안 됩니다.

## 1. 올리기 — GitHub Pages (무료, 5분)

1. github.com에서 새 저장소 만들기. 이름 아무거나, **Public**
2. `Add file` → `Upload files` 로 위 파일 전부 올리고 커밋
3. `Settings` → `Pages` → Source를 `Deploy from a branch`, 브랜치 `main` / `(root)` 로 저장
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 주소가 열립니다

사내 서버나 Netlify, Vercel, Cloudflare Pages도 똑같이 됩니다. 폴더째 올리기만 하면 됩니다.

## 2. 홈 화면에 붙이기

1. **Safari로** 그 주소를 엽니다 (크롬 아님 — 아이폰은 Safari여야 제대로 설치됩니다)
2. 하단 공유 버튼 → `홈 화면에 추가`
3. 홈 화면 아이콘으로 실행하면 주소창 없이 전체화면으로 뜹니다

## 3. 05:00 알람

아이폰 웹 앱은 예약 알림을 못 보냅니다. 이건 우회로가 없습니다.
**시계 앱 → 알람 → 04:50, 매일 반복**으로 걸어두세요.
기본 알람이 어떤 앱 알림보다 확실합니다.

## 기록은 어디에 남나

이 아이폰 Safari의 저장 공간에만 남습니다. 서버로 안 나갑니다.

- 홈 화면에 추가한 웹 앱은 데이터가 유지됩니다
- 다만 **Safari 방문 기록·데이터 지우기**를 하면 함께 지워집니다
- 아이폰을 바꾸거나 앱을 지우면 사라집니다

그래서 '기준' 탭에 **백업 파일 내려받기**를 넣었습니다.
2주에 한 번, 최대 테스트 하는 날 같이 눌러서 파일 앱에 두세요.
복원은 그 JSON 파일을 열어 전체 복사 → 붙여넣기 칸에 넣고 `복원하기`.

## 업데이트
